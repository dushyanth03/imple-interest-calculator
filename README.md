# Simple Interest Calculator

## Description
A simple calculator that calculates interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal: Initial amount of money.
- Rate: Annual interest rate in percentage.
- Time: Duration in years.

## Example
- Principal: 10000
- Rate: 5%
- Time: 2 years
- Simple Interest: 1000

## How It Works
1. Enter the principal amount.
2. Enter the annual interest rate.
3. Enter the time period in years.
4. Calculate the interest using the formula.
5. Display the result.

## Conclusion
This project demonstrates how to calculate simple interest using a mathematical formula.
